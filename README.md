# dcarrero/scoop-bucket

[Scoop](https://scoop.sh/) manifests for command-line tools by David Carrero.

```powershell
scoop bucket add dcarrero https://github.com/dcarrero/scoop-bucket
scoop install dcarrero/mboxshell
```

| Tool | What it is |
|------|------------|
| [mboxshell](https://github.com/dcarrero/mboxshell) | Fast terminal viewer for MBOX files of any size |

Each manifest in `bucket/` is written by the release workflow of its project on every tagged
version. Please report problems in the project's repository, not here.
